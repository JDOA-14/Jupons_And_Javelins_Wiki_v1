# Chapter 7: Treasure — Table-Ready Summary

Treasure = coins, valuables, trade goods, art, gemstones, and magic items.  
Use **Treasure Themes** (Arcana, Armaments, Implements, Relics) to flavour hoards and guide random tables.

---

## Treasure Themes

| Theme     | Typical Treasure                                      |
|----------|--------------------------------------------------------|
| Arcana   | Gemstones plus magic items of an eldritch or esoteric nature |
| Armaments| Coins or trade bars plus magic items useful in battle  |
| Implements| Coins, trade bars, or trade goods plus utility items  |
| Relics   | Art objects plus magic items with religious origins or purposes |

# Crafting Magic Items

## Requirements

- You (and assistants) must:
  - Have **Arcana** proficiency  
  - Have proficiency with the **required tool**  
  - Have all **spells** the item can cast prepared each crafting day  
- Need **raw materials** (availability determined by DM)

---

## Magic Item Tools

| Item Category  | Required Tool |
|----------------|---------------|
| Armor          | Leatherworker's Tools, Smith's Tools, or Weaver's Tools (as appropriate) |
| Potion         | Alchemist's Supplies or Herbalism Kit |
| Ring           | Jeweler's Tools |
| Rod            | Woodcarver's Tools |
| Scroll         | Calligrapher's Supplies |
| Staff          | Woodcarver's Tools |
| Wand           | Woodcarver's Tools |
| Weapon         | Leatherworker's Tools, Smith's Tools, or Woodcarver's Tools (as appropriate) |
| Wondrous Item  | Tinker's Tools or tool appropriate to its base item |

---

## Magic Item Crafting Time & Cost

| Item Rarity | Time*   | Cost*     |
|-------------|---------|-----------|
| Common      | 5 days  | 50 gp     |
| Uncommon    | 10 days | 200 gp    |
| Rare        | 50 days | 2,000 gp  |
| Very Rare   | 125 days| 20,000 gp |
| Legendary   | 250 days| 100,000 gp|

\* Time and cost are **halved** for a consumable item other than a Spell Scroll. (Scrolls use PHB scribing rules.)

- **Work per day**: 8 hours  
- **Assistants**: divide total time by number of crafters (usually 2 max, unless DM allows more)  
- **Materials availability**:  
  - City: 75% chance  
  - Other settlement: 25% chance  
  - If unavailable, wait 7 days and roll again

# Magic Item Flavour – Quick Tables

Use these to add flavour (not power) to magic items.

## Magic Item's Creator or Intended User (1d20)

Includes options like: Aberration-made, Celestial, Dwarf, Elf, Fey, Fiend, Giant, Gnome, Human, Undead, Elemental influences, etc. (as per full table).

## Magic Item's History (1d8)

1. Arcane (created for an order of spellcasters)  
2. Bane (made to oppose a creature type)  
3. Heroic (once wielded by a great hero)  
4. Ornament (honours a special event)  
5. Prophecy (features in a prophecy)  
6. Religious (used in ceremonies)  
7. Sinister (tied to an evil deed)  
8. Symbol of Power (royal regalia / badge of office)

## Magic Item's Minor Property (1d20)

Examples:  
- Beacon (can shed light)  
- Compass (points north)  
- Guardian (+2 initiative)  
- Harmonious (attune in 1 minute)  
- Unbreakable (cannot be broken)  
- Waterborne (floats; swim advantage)  

## Magic Item's Quirk (1d8)

Examples:  
- Blissful (optimism, butterflies)  
- Covetous (obsessed with wealth)  
- Loud (noisy when used)  
- Metamorphic (changes appearance)  
- Repulsive (feels unpleasant to bear)

# Cursed Items – Key Rules

- Identify and similar magic usually **don’t reveal curses**  
- Attunement to a cursed item **can’t be voluntarily ended**  
- Must break the curse (e.g. *Remove Curse*) first

---

# Sentient Magic Items – Core

- Have **Int, Wis, Cha** scores  
- Have **alignment**  
- Communicate (emotion, speech, or telepathy)  
- Perceive surroundings to a limited range  
- May have a **special purpose** (destroy undead, seek creator, etc.)  
- Can create **conflict** with wielder if goals misalign

Sentient items can:

- Withhold properties  
- Demand actions  
- Attempt to **charm/control** bearer (Charisma save vs DC 12 + item’s Cha mod)

# Using Random Magic Item Tables

When treasure includes magic items:

1. Choose a **Treasure Theme** (Arcana, Armaments, Implements, Relics).  
2. Decide rarity: **choose** or roll on **Magic Item Rarities** table.  
3. Roll on the matching **theme + rarity** table (e.g. *Arcana – Rare*).  
4. Add **coins, trade bars, gems, and art** as needed from above tables.  

The **Arcana / Armaments / Implements / Relics** tables (Common → Legendary) give you complete random item lists to roll from.
