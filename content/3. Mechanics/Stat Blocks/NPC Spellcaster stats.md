### Spellcasting. 
Each caster uses a set of spells based on their Type and Rank. Check their Type for which spells.

Spellcasters usually use all their 1/day each spells before resorting to at-will spells. Spells with an asterisk* are concentration spells. When casting a spell as a bonus action, a caster uses their action to cast a cantrip in the same turn.

Spellcaster ranks. Use casters based on their Rank, using this table:

|   |   |   |   |
|---|---|---|---|
|Rank|CR|Elite enemy for a...|Normal enemy for a...|
|1|1/2|1st to 2nd-level party|3rd to 4th-level party|
|2|1|3rd to 4th-level party|5th to 10th-level party|
|3|3|5th to 8th-level party|11th to 16th- level party|
|4|6|9th+ level party|17th+ level party|
If you want a very weak spellcaster (normal enemy for a 1st- to 2nd-level party), use a Rank-1 spellcaster with 8 hit points that only uses cantrips with no leveled spells.

Every rank of spellcaster has a set of cantrips, a set of spells for their rank, and knows the spells of the rank below theirs (if any). This means you’ll never have to keep track of more than about four leveled spells for each spellcaster.

Spellcaster types. Each spellcaster type comes with 4 ranks of spells plus a spellcasting ability. Their spellcasting ability is (12 + 2xRank), and their other mental stats are each 12.

Cantrips. Each spellcaster knows a few cantrips. Cantrips normally scale with level, but for this stat block, they use the following scaling:

| Rank 3      | 2 dice          | 16      | +8              |
| Rank 4      | 3 dice          | 18      | +10             |

## Legendary spellcasters. 
For a spellcaster boss that you want to take on an entire party by themselves, apply the following changes to a spellcaster that would normally be an elite enemy for the party’s level:

- They have twice as many hit points.
- They gain the Legendary Resistance trait, which allows them to automatically succeed on a failed saving throw a certain number of times per day (check the legendary spellcasters table).
- They gain an extra use of their strongest spells.
- They gain three Legendary Actions - actions used at the end of another creature’s turn, and which are restored at the end of the spellcaster’s turn - and can use them in the following ways:
	- Move. The spellcaster moves up to its speed.
	- Cantrip. The spellcaster casts a cantrip.
	- Spell (costs 2 actions). The spellcaster casts a spell with a casting time of 1 action.
